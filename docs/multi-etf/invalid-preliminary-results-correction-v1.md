# 予備計算の無効化と結論訂正

以前のYahooデータ計算は品質検査をsynthetic=Trueで回避していた。欠損の前日値・出来高1による補作、欠損取引日の削除、分割調整済み価格のraw指定、企業行動・分配金未解決、売買単位未照合、期間境界の重複、取得時刻の仮置きが含まれる。これらの損益・PF・取引回数を戦略の採否判断に使用してはならない。

対象はpreliminary-reference-2026-11-21.json、preliminary-summary-2026-11-21.json、final-preliminary-report-2026-11-21.json、unverified-1306-backtest-2026-11-21.json、consolidated-unverified-2026-11-21.json、final-status-v2-2026-11-21.json、およびresearch-record-2026-11-21-real-data.mdの採否と損益に関する記載。元ファイルは失敗試行の履歴として保持する。

「全戦略が採用基準を満たさない」「トレンドは費用で負ける」等の結論を撤回する。正しい状態は、**品質条件を満たした実データ収益性評価は未実施、収益性判断不能、採用戦略なし**。これは赤字を確認したという意味ではない。今回の一日分のOHLC確認だけでも評価開始条件は満たさない。

条件やパラメータの変更、品質検査の回避による再試行は行わない。今後は出所・取得時刻・SHA・カレンダー・当時の売買単位・企業行動・分配金・費用を照合してから評価する。
