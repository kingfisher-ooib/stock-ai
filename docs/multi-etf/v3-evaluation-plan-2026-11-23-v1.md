# I6評価・登録の実装前仕様

2026-11-23。既存I1〜I5・設定・結果は保持し、合成専用の評価/登録部品を追加する。実データ実験の許可ではなく、今回の動作確認はpytest内だけ。

- 完了したI5結果だけに指標を計算。停止/未完了はmetrics=null、理由を保存。会計矛盾は評価例外とし、成功として保存しない。
- Entry/ClosedTradeと元の合成OHLCV・注文費用から原価・売却純額・影響費用・手数料を再計算。口数は分割連鎖と照合する。日次現金、保有時価、D債権、R債権、最終資産差と分配帰属後取引損益を照合。
- 純損益・期待値・PF等は確定額のR帰属を使用。DのDD/シャープ/資金稼働率とRのDD/シャープは別表示。主DDはD。税引前・費用控除後で、平均/比率など表示用統計はfloat、会計金額はFraction/Decimalで厳密照合する。
- 年率リターンは旧実装に合わせ252セッション以上、無リスク金利0のシャープを明記。件数/期間/損失/勝ちが不足する指標はnullと理由。指標合算スコアを作らない。
- CIは旧計画の決済日10営業日循環ブロック、seed=20261121、1000回を継承。30取引未満/10セッション未満は算出しない。同日銘柄間依存を保持。正でも合成結果による優位性・採用は認めない。
- 登録は新規ディレクトリへ排他作成し、入力/原本バイト/設定/対象/期間/as_of/優先順/コードSHA/ケースID/予算を固定。実データ不可。ケースは登録時に固定し、同ケース再実行不可、最大予算は450を上限として登録集合以下。
- 実行前に開始記録を排他作成し、失敗/中断でも消さない。完了/停止/例外を別の新規outcomeへ保存。開始だけで終了しなかったものは消費済み中断として扱い、無断で再試行しない。ローカルファイルロックで競合を拒否。
- ハッシュはバイト整合の検査であり、市場データの真正性や悪意の改ざん耐性を認証しない。失敗記録へ原本内容や資格情報を転記しない。
- 今回、リポジトリ内に戦略比較の実験を登録/実行しない。テストの一時領域でのみ登録・失敗・予算消費を検証。収益性は未判定、採用戦略なし。
