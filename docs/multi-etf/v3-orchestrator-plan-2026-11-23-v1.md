# I5合成実行器の実装前登録

2026-11-23。既存I1〜I4/v1/v2と戦略条件・研究結果を保持し、独立した合成専用実行器を追加する。これは新しい実データ実験の登録ではなく、戦略比較の実行予算は0のまま。実施は正常/異常系の合成統合テストだけ。

- 入力はI1モデルを再検査し、原本バイト列SHAとas_ofを要求。実市場出所・非合成ラベルは拒否する。期間は入力の固定端点、優先順は全候補を明示。値幅や全量約定の実市場保証はない。
- A/B/Cは既存signal/指標を再利用し、資金10万円、100円予算、最大3/5%、保有5日、前日判断/翌寄付、終値stop/SMA20、日次2%を既存設定から引き継ぐ。費用はcfgと合成執行規則の一致を要求。実費用認証ではない。
- v2同様、単純保有だけは開始前営業日に注文を固定。A/B/Cは評価初日引けから翌日注文を作る。単純保有の候補差替え・日次stop・再配分なし。現金は売買しない。
- 毎日、前日口数による権利保存→市場分割→利用可能分配入金→予定寄付売り→凍結済み買い→引け入金/評価→翌日売り/買いを処理する。売却予定枠/当日入金で前日注文を増やさない。
- 特徴量用には判断時点までに既知かつ市場切替済みの分割だけを過去OHLCVへ反映。元データは変更しない。後日確定額を注文、数量、stop、日次制限へ流用しない。
- 未知額によるD評価停止は期間全体の未評価として保存し、後日のRだけで完了成績にしない。計算不能/不正/欠損の例外と、明示的な未約定を区別する。
- 最終日は開始前の方針で全保有を引け仮想決済する。合成引けで全量成立する仮定を明示し、寄付専用の旧部品を上書きしない。新しい終了部品の返却状態はterminalで、以後の注文作成に使う実行経路は設けない。終了時の現金は評価用で、実口座の再投資可能日時を表さない。
- D曲線/注文/口数を固定後、最新の確定額を権利IDで各過去フレームに対応させたR曲線を別に作る。現金と既払額は当該フレーム時点を使い、分配金の二重計上を防ぐ。R不明は完了指標を出さない。
- 終了ポジション/現金台帳/権利履歴/注文/拒否理由/日次段階を返す。統計・採否・AIはI6以降。CLIの実データ解禁・既存結果の再計算・性能探索は行わない。
